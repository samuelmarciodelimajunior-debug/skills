# Shopify MCP

Setup e gerenciamento de lojas Shopify.

**Store creation:** `get-new-store-previews` cria preview de loja a partir de descrição curta.

**Management:** products (search/create/update/bulk), collections, orders, customers, inventory, analytics (ShopifyQL), discounts, images.

**GraphQL:** `graphql_query`/`graphql_mutation` para qualquer recurso do Admin API (gift cards, metafields, metaobjects, pages, markets, translations, etc).
