# Stripe MCP

Pagamentos, faturas, assinaturas, cupons, refunds, payment links. Inclui Stripe API direto (`stripe_api_execute`, `stripe_api_search`) para qualquer recurso.

**Principais:** create_customer/product/price/invoice/payment_link/coupon/refund, cancel/update_subscription, list_disputes, retrieve_balance, search_stripe_documentation, stripe_integration_recommender.
