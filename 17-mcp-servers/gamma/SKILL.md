# Gamma MCP

Gerar apresentações, documentos, webpages, social posts via IA.

**Tools:** generate, generate_from_template, get_themes, get_folders, get_gammas, get_generation_status, read_gamma.

**Templates:** usar `get_gammas(type="template")` para descobrir templates válidos antes de `generate_from_template`.

**Atenção:** não edita gammas existentes — usuário deve customizar no editor Gamma.
