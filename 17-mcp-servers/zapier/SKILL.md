# Zapier MCP

Conecta a 8.000+ apps via Zapier.

**Tools:** list_enabled_zapier_actions, discover_zapier_actions, enable_zapier_action, disable_zapier_action, execute_zapier_read_action, execute_zapier_write_action, list_zapier_skills, get_zapier_skill, create_zapier_skill, update_zapier_skill, delete_zapier_skill, auto_provision_mcp, get_configuration_url, send_feedback.

**Workflow:** sempre `list_enabled_zapier_actions` antes de executar. Se app não habilitado: `discover_zapier_actions` → `enable_zapier_action`.
