# Microsoft Learn MCP

Documentação oficial Microsoft/Azure.

**Tools:**
- `microsoft_docs_search` — busca chunks (max 500 tokens, até 10 resultados)
- `microsoft_code_sample_search` — snippets de código (até 20 resultados, filtro por linguagem)
- `microsoft_docs_fetch` — converte página completa para markdown

**Workflow:** search → code-sample → fetch (breadth → examples → depth).
