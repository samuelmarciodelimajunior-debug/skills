# Figma MCP (oficial)

Bridge bidirecional code↔design para Figma, FigJam, Figma Make, Figma Slides.

**Ler de Figma:** get_design_context, get_screenshot, get_metadata, get_figjam, get_variable_defs.
**Escrever no Figma:** use_figma, generate_figma_design, create_new_file, upload_assets.
**Code Connect:** get_code_connect_map, add_code_connect_map, send_code_connect_mappings.
**Diagramas:** generate_diagram, get_figjam.

**Skills obrigatórias antes de usar:** `/figma-use`, `/figma-generate-design`, `/figma-generate-library`, `/figma-code-connect`, `/figma-use-figjam`, `/figma-generate-diagram`.
