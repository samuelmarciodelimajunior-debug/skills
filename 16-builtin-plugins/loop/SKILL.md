# loop

Roda um prompt ou slash command em intervalo recorrente.

**Invocação:** `/loop 5m /foo` (default 10min)

**Quando usar:** tarefas recorrentes, polling de status, execução em intervalo ("checar deploy a cada 5min", "rodar /babysit-prs continuamente"). NÃO usar para tarefas one-off.
