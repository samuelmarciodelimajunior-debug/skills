# keybindings-help

Customizar atalhos de teclado, rebind de teclas, adicionar chord bindings ou modificar `~/.claude/keybindings.json`.

**Exemplos:** "rebind ctrl+s", "adicionar chord shortcut", "mudar tecla de submit", "customizar keybindings".
