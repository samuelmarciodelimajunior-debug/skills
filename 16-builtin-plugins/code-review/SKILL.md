# code-review

Revisa o diff atual em busca de bugs de correção. Níveis: low/medium (poucos achados de alta confiança) e high/max (cobertura ampla, achados incertos).

Use `--comment` para postar achados como comentários inline em PR.

**Invocação:** `/code-review` ou `/code-review --comment`
